## Items 5–8

- Arrow import: explicit scalar schemas, per-batch/call bounds, one native staging
  savepoint and caller-owned commit. Late schema/producer/statement/budget failures
  preserve earlier transaction work. Missing optional dependency refuses explicitly.
- Prefix search: required bit 11 and `fulltext_v4_`; bounded prefix postings and
  expansion, exact whole-term BM25 oracle, old-reader/foreign-write isolation.
- Relationship FTS: required bit 12; property names refer to actual stored column
  positions (which already include `_from`/`_to`). Physical parallel edges and loops
  survive update/delete/rebuild, backup, logical transfer and native crash replay.
- Graph projections: immutable snapshot-qualified multigraph, degree and weak
  components, typed selection/reader validation, limits and cooperative cancellation.
  Independent reachability oracle; no persistent projection catalog or write modes.
