## Logical-transfer matrix

Two profiles × two fixtures: native labels alone and labels combined with DATE,
DECIMAL and LIST/STRUCT/MAP/ANY. Each fixture has one candidate export, ordinary
and resumable candidate imports, and ordinary/resumable refusal by each of three
old importers: **4 exports + 8 imports + 24 refusals = 36 worker checks**.

Fixtures preserve two nodes, parallel relationships and a self-loop. One node
loses its base label and gains `LabelA`/`λ`; the other becomes unlabeled. Imports
use one-row batches, independent new store identity, endpoint remapping, two cold
verified reopens and repeated successful acknowledgement for resume. Nested types
and values are checked independently. Export and cold-read profiles are pure or
accelerated as selected; public import retains its own default write configuration.
This matrix does not claim an explicit import codec override. Separate source
process-cut tests exercise private import writers under both codecs.

Every old importer returns `GrafxRecoveryRefused`, operation `logical_transfer`,
reason `unsupported_format`, without changing any artifact or destination-parent
file/directory, including an empty resume workspace. The candidate does not strip

## Reproduce

Build/install the candidate and each historical wheel in separate local venvs.
Supply matching wheel/interpreter pairs and fresh output roots; do not replace an
existing receipt or use a production store.

```powershell
python tools/qualify_temporal_wheels.py --current-python path/to/current/Scripts/python.exe --current-wheel path/to/current.whl --source-root . --old-python path/to/old/Scripts/python.exe --old-wheel path/to/old.whl --capability node_labels --profile pure --output path/to/fresh-native-pure
python tools/qualify_transfer_wheels.py --current-python path/to/current/Scripts/python.exe --old-python path/to/old-importer/Scripts/python.exe --labels-only --output path/to/fresh-transfer
```

For the recorded native matrix, repeat the old pair three times and run both
profiles. For transfer, repeat the three old importer paths. Native qualification
with wheel/source arguments automatically proves package identity. Transfer worker
receipts contain all package hashes; compare each with its wheel through
`tools.qualify_temporal_wheels.prove_package`, supplying the checkout for current
workers, as in this audit. Origin checking alone is not the complete package proof.
